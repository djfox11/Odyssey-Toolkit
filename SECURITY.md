# Security Policy

Only the current release line and the latest `main` branch are considered for
security fixes while Odyssey Toolkit approaches 1.0.

Do not disclose a suspected vulnerability in a public issue. Use GitHub's private
vulnerability reporting or open a private security advisory for this repository.
Include the affected version, Blender version, reproduction steps, impact, and any
known workaround. Do not attach copyrighted game data, keys, or a complete ROMFS.

Security reports are assessed separately from ordinary feature requests. A fix may
be released outside the normal stabilization schedule when it protects user data,
local files, or the integrity of imported Blender projects.
